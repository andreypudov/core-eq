#+TITLE: CoreEQ
#+SUBTITLE: 適用於 macOS 的全系統等化器

CoreEQ 會等化 *你聽到的一切*——音樂、影片、通話、遊戲——無論聲音來自哪個 App，都不需要虛擬音訊驅動程式或核心延伸功能。它使用 Core Audio 原生的程序音訊擷取 API，因此不會在系統中安裝任何東西，CoreEQ 沒有執行時也不會留下任何痕跡。

[[./design/screenshots/core-eq-1.10.png]]

* 特色

- *所有 App，不需驅動程式。* 不會在系統中安裝任何東西（你可以自行確認），結束 CoreEQ 會立即交還音訊。
- *圖形與參數在同一處理鏈中。* ISO 十一頻段倍頻程階梯，另加最多十六個你自己的鐘形、架形與通濾波器。
- *即時、可編輯的響應曲線*，以音訊實際經過的同一組係數繪製，疊加在即時頻譜分析儀之上。
- *二十二個內建預設組，加上你自己的預設組*，每個內建預設組都附有一行用途說明。
- *內建 AutoEq 目錄*：依型號搜尋數千筆耳機校正，儲存前先試聽，並儲存為你自己的預設組。只有在你打開它時才會連線。
- *AutoEq 與 EqualizerAPO 匯入及輸出*，來自其他地方的校正按幾下就能載入。
- *自動增益* 讓預設組維持原本的響度，比較預設組時比的是音色，而不是音量。
- *A/B 比較* 同一預設組的兩個版本。
- *依輸出裝置分別設定*：耳機回來時，耳機的曲線也跟著回來。
- *選單列控制*，可在任何預設組之上使用快速等化（低音、中音、高音）。
- *感知錄影*：螢幕錄影擷取系統音訊時，CoreEQ 會暫時讓開，錄下的聲音就不會重複。
- *不干擾指定 App*：排除 DAW 或任何其他 App，它的聲音會原樣直接輸出（需要 macOS 26 或以上版本）。

每項功能都在 [[file:docs/USER_GUIDE.org][使用手冊]]（英文）中有說明。

* 系統需求

- macOS *14.2* 或以上版本
- 處理系統音訊的權限。CoreEQ 會先說明用途，然後才請求

* 安裝

** Homebrew（建議）

#+begin_src sh
brew tap andreypudov/core-eq
brew trust andreypudov/core-eq
brew install --cask core-eq
#+end_src

之後以 =brew update && brew upgrade --cask core-eq= 更新。

CoreEQ 以自己的憑證簽署，因此音訊權限在更新後依然保留；但它未經 Apple 公證，macOS 可能會阻擋第一次打開。請在「系統設定」→「隱私權與安全性」中允許，或清除隔離標記：

#+begin_src sh
xattr -dr com.apple.quarantine /Applications/CoreEQ.app
#+end_src

** 從原始碼建置

需要 Xcode 26 或以上版本。在本機建置的 App 不會被隔離，因此 CoreEQ 打開時不會出現 Gatekeeper 警告：

#+begin_src sh
git clone https://github.com/AndreyPudov/core-eq.git
cd core-eq
make install
#+end_src

這會建置 Release 版本並安裝到 =/Applications=。

** 預先建置的版本

從 *Releases* 頁面下載最新的 =CoreEQ-x.y.zip=，解壓縮後將 =CoreEQ.app= 移到 =/Applications=，再依上文清除隔離標記。

* 開始使用

1. 打開 CoreEQ。選單列中會出現推桿圖像；Dock 中沒有圖像。
2. 允許 *系統錄音*。CoreEQ 會打開視窗，說明此權限的用途，並在你按一下 *允許⋯* 時請求——它需要此權限來處理你聽到的聲音。任何內容都不會被錄製、儲存或傳送。
3. 選擇一個預設組。聲音會立即改變。

遇到問題？[[file:docs/USER_GUIDE.org][使用手冊]] 中有疑難排解章節，「設定」→「診斷」可產生報告，附在錯誤回報中。
