CoreEQ эсир илтекен *пӗтӗм сасса* — музыкӑна, видеона, шӑнкӑравсене,
вӑййисене — эквалайзер урлӑ ярать, сасӑ хӑш приложенирен килнинчен
килмест, виртуаллӑ аудио драйверсӑр тата тӗшӗ расширенийӗсӗр. Вӑл Core
Audio-н процессен сассине тытакан хӑйӗн API-ӗпе ӗҫлет, ҫавӑнпа тытӑма
нимӗн те лартӑнмасть, CoreEQ ӗҫлемен чух нимӗнле йӗр те юлмасть.

[[./design/screenshots/core-eq-1.10.png]]

* Тӗп пултарулӑхӗсем

- *Пур приложени те, драйверсӑр.* Тытӑма нимӗн те лартӑнмасть — ҫакна хӑвӑр
  тӗрӗслеме пултаратӑр, — CoreEQ-ран тухсанах сасӑ ҫийӗнчех каялла таврӑнать.
- *Графика тата параметрлӑ пӗр ретре.* Вун пӗр полосаллӑ ISO октава шкали,
  ҫумне хӑвӑрӑн вун ултӑ таран фильтр: чан, полка тата касакан фильтрсем.
- *Чӗрӗ, улӑштарма май пур АЧХ графикӗ*, сасӑ иртекен коэффициентсенех
  ӳкернӗскер, вӑхӑт ҫийӗнчи спектр анализаторӗ ҫийӗнче.
- *Йӗркеленӗ ҫирӗм икӗ пресет тата хӑвӑрӑннисем*, кашни йӗркеленин мӗн
  валли пулнине ӑнлантаракан пӗр йӗрке пур.
- *AutoEq каталогӗ ӑшра*: модель тӑрӑх пин-пин наушник тӳрлетӗвне шырӑр,
  упраса хӑвариччен итлесе пӑхӑр, хӑвӑр пресет пек упрӑр. Интернета вӑл
  эсир уҫсан ҫеҫ тухать.
- *AutoEq тата EqualizerAPO импорчӗпе экспорчӗ*: ытти ҫӗртен илнӗ тӳрлетӗве
  темиҫе пуссах тиеме пулать.
- *Хӑй тӗллӗн вӑйлату* пресета пуҫламӑш сасӑ хӑвачӗпе тытать, ҫавӑнпа
  пресетсене танлаштарнӑ чух сасӑ хӑвачӗ мар, янӑрашӗ танлаштарӑнать.
- Пӗр пресетӑн икӗ версине *A/B танлаштару*.
- *Кашни кӑлару хатӗрӗ валли уйрӑм ӗнерлевсем*: наушниксем таврӑнсан
  вӗсен кукӑрӑшӗ те таврӑнать.
- *Меню йӗркинчен ертсе пыни*, кирек хӑш пресет ҫийӗн хӑвӑрт эквалайзер
  (пас, варри, ҫӳлли).
- *Ҫырӑва шута илет*: экран ҫырӑвӗ тытӑм сассине тытнӑ чух CoreEQ айккинелле
  пӑрӑнать, ҫырӑвра сасӑ икӗ хутланмасть.
- *Приложенисене тӗкӗнмесӗр хӑварма пулать*: DAW е урӑх приложение кӑларса
  пӑрахӑр, унӑн сасси улшӑнмасӑр тӳрех кӑларӑва каять (macOS 26 е ҫӗнӗрех).

Кашни пултарулӑх [[file:docs/USER_GUIDE.org][усӑ куракан руководствинче]] (акӑлчанла) ҫырса кӑтартнӑ.

* Тытӑм ыйтӑвӗсем

- macOS *14.2* е ҫӗнӗрех
- Тытӑм сассине тирпейлеме ирӗк. CoreEQ ӑна мӗн валли кирлине малтан

* Лартасси

** Homebrew (сӗнетпӗр)

#+begin_src sh
brew tap andreypudov/core-eq
brew trust andreypudov/core-eq
brew install --cask core-eq
#+end_src

Каярахпа ҫӗнетме: =brew update && brew upgrade --cask core-eq=.

CoreEQ хӑйӗн сертификачӗпе алӑ пуснӑ, ҫавӑнпа аудио ирӗкӗ ҫӗнетӳсем хыҫҫӑн
та упранать, анчах Apple ӑна нотариуслӑ тӗрӗслемен, ҫавӑнпа macOS пӗрремӗш
уҫӑлӑва чарма пултарать. Ӑна Тытӑм ӗнерлевӗсем → Вӑрттӑнлӑх тата хӳтлӗх
ҫинче ирӗк парӑр е карантин паллине пӑрахӑр:

#+begin_src sh
xattr -dr com.apple.quarantine /Applications/CoreEQ.app
#+end_src

** Ҫӑлкуҫ кочӗнчен пухасси

Xcode 26 е ҫӗнӗрех кирлӗ. Хӑвӑр пухнӑ приложенисем карантина лекмеҫҫӗ,
ҫавӑнпа CoreEQ Gatekeeper асӑрхаттарӑвӗсӗрех уҫӑлать:

#+begin_src sh
git clone https://github.com/AndreyPudov/core-eq.git
cd core-eq
make install
#+end_src

Ку команда Release версие пухать те ӑна =/Applications= ӑшне лартать.

** Хатӗр пуху

*Releases* страницӑран юлашки =CoreEQ-x.y.zip= илсе ҫитерӗр, уҫӑр,
=CoreEQ.app= файлне =/Applications= ӑшне куҫарӑр, унтан ҫӳлте ҫырнӑ пек
карантин паллине пӑрахӑр.

* Пуҫласси

1. CoreEQ уҫӑр. Меню йӗркинче шуҫӑмсен паллӑ курӑнать; Dock-ра паллӑ ҫук.
2. *Тытӑм сассине ҫырма* ирӗк парӑр. CoreEQ хӑйӗн чӳречине уҫать, ирӗк мӗн
   валли кирлине ӑнлантарать, *Ирӗк пар…* пуссан ыйтать: эсир илтекен сасса
   тирпейлеме ӑна ҫавӑ кирлӗ. Нимӗн те ҫырӑнмасть, упранмасть, ярӑнмасть.
3. Пресет суйлӑр. Сасӑ ҫийӗнчех улшӑнать.

Мӗн те пулин ӗҫлемест-и? [[file:docs/USER_GUIDE.org][Усӑ куракан руководствинче]] йывӑрлӑхсене пӗтерес
пай пур, Ӗнерлевсем → Диагностика вара йӑнӑш ҫинчен пӗлтерӗве хушмалли
отчет тӑвать.
